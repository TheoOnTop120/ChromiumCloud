Overview

Getting started

Quick guide for administrators.

  • Create users in the Users tab (password min 12 chars).
  • Each user gets an isolated browser on first login.
  • Monitor sessions and resources in Sessions / Resources.
  • Stop or restart a stuck browser from the Sessions tab.
  • All admin actions are recorded in the Audit log.
